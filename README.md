# 猪咪备忘录

“猪咪备忘录”是一个本地运行的 Windows 文本、图片与文件剪贴板历史工具，使用 Python、PySide6 和 SQLite。项目由 ClipboardPlus V1 原位升级而来，继续兼容 V1 数据目录，因此已有历史会在数据库迁移后保留。

应用图标已替换为项目 `assets/app_icon.png` 中的猫娘插画，并生成了适用于 Windows 与 Android 的多尺寸图标。

## Windows 安装包

- 安装程序：`release/ZhumiMemo-Setup-4.3.8.exe`
- 默认安装位置：`%LOCALAPPDATA%\Programs\ZhumiMemo`
- 安装程序可创建桌面快捷方式，并可选择登录后自动启动。
- 本地构建包未使用商业代码签名证书，Windows SmartScreen 可能显示未知发布者提示。

重新构建安装包：

```powershell
powershell -ExecutionPolicy Bypass -File .\build_windows.ps1
```

## 启动与退出

- 日常启动：双击桌面上的“猪咪备忘录”，或运行 `start_zhumi_memo.bat`。
- 首次配置或环境损坏时：运行 `setup.bat`。
- 隐藏窗口：按 `Esc` 或点击关闭按钮；程序仍在系统托盘运行。
- 完全退出：右键系统托盘图标，选择“退出”。

默认全局快捷键是 `Alt + V`，可在设置页修改。快捷键必须包含至少一个修饰键，并搭配字母、数字或 `F1`—`F24`。

## 主要功能

- 文本、图片和文件是三个独立历史模块，可用窗口顶部的“文本 / 图片 / 文件”按钮切换。
- “编辑”页是独立的即时编辑台：可自由输入文本，粘贴、选择或拖入图片，支持单独复制文本、单独复制图片、同时复制文本与图片，以及一键清空。编辑内容仅保留在当前运行会话，不会写入历史数据库。
- 背景增加左下到右上的天蓝、淡蓝、蓝白渐变，并以轻量 QPainter 绘制水彩晕染和半透明笔触；绘制结果按窗口尺寸缓存，不增加第三方图形依赖。
- 文本、图片、文件、编辑四个模块分别使用独立本地立绘背景，切换时同步更新并以约 170ms 的淡出/淡入过渡呈现。
- 模块切换支持快速连续点击合并，只落实最后选择的模块；窗口隐藏或最小化时会立即收束动画并取消过期的置前重试，避免闪烁、旧页面残留或隐藏后抢焦点。
- 主窗口使用同主题自绘边框和标题栏，支持标题栏拖动、双击最大化/还原、最小化、关闭到托盘，以及窗口四边与四角缩放。
- 设置中可选择呼出后是否持续置顶；默认使用普通窗口层级，仍会在 Alt+V 或托盘呼出时恢复、激活并获得焦点。
- 每次呼出文本、图片或文件模块都会自动回到最新一条记录，底部也提供“回到顶部”按钮。
- 图片最多保存 200 张普通记录；收藏和固定图片不计入自动清理数量。
- 文件从剪贴板进入历史后在后台分块缓存，不阻塞主窗口；右键可复制、打开、打开文件所在位置或另存为。复制 JPG、PNG、GIF、WebP、TIFF、HEIC、AVIF 等常见图片文件时，会自动进入图片历史而非文件历史。
- 文件缓存容量可在 128MB—2048MB 之间设置。超限时先清理最旧且未收藏、未固定的文件记录。
- 自动保存文本剪贴板，内容重复时更新时间并移到顶部。
- 左侧按“全部、固定、收藏、文本、URL、代码、JSON、路径、Prompt”筛选。
- 顶部实时搜索内容或来源程序。
- 日期筛选支持今天、昨天、最近 7 天、最近 30 天和自定义日期范围，并可与关键词搜索组合使用。
- `↑` / `↓` 选择；`Enter` 复制并隐藏，双击文本/图片进入完整预览，双击文件直接打开。
- 收藏和固定内容不会因历史数量上限而被自动清理。
- 图片同样支持收藏、固定、复制、删除和移动分类。
- 文本和图片都可以通过右键添加或编辑备注；保存非空备注后会自动收藏，备注也可以被顶部搜索找到。
- 有备注的文本或图片可在右键菜单中单独复制备注，也可将备注与文本或图片放入同一份剪贴板数据中复制。
- 可创建自定义分类；右键分类可重命名或删除，右键记录可移动到系统分类或自定义分类。
- 窗口右下角可切换“固定窗口 / 普通窗口”。
- 文本、图片和文件记录的右键菜单均支持“打开文件所在位置”：文本打开数据目录，图片打开图片缓存目录，文件打开缓存文件或原文件的所在目录。
- URL 可用浏览器打开，也可单独复制域名。
- 本地文件路径可打开目标或所在文件夹。
- 尽力记录来源程序。受 Windows 和来源软件实现方式影响，少数记录可能没有来源或来源不准确。
- 托盘菜单可暂停/恢复文本、图片和文件记录，打开设置、清空历史和退出。
- 单击托盘图标：隐藏时打开，最小化或被遮挡时恢复并置前，已经位于前台时再次单击隐藏；全局快捷键始终只负责打开和置前。
- 设置页支持全局快捷键、最大文本数量、最大普通图片数量（5—200）、文件缓存容量（128MB—2048MB）、可缓存文件格式、数据存放位置和 Windows 登录后自动启动。文件格式支持逗号、空格或分号分隔；`*` 表示全部非图片格式，留空则不缓存文件。
- 设置页新增“内容面板透明度”滑块（0%—100%，默认 42%）；数值越高越能看见模块立绘，拖动时实时预览，取消设置会恢复原值。
- 超长内容只向列表提交摘要；完整内容仍保存在数据库中。
- 完整文本和图片预览窗口支持自由调整大小、最大化和最小化。
- 双击文本打开完整内容，双击图片打开大图，双击文件打开缓存文件；不会再因双击而隐藏到托盘。
- 大图预览支持滚轮缩放、鼠标拖动、恢复原始大小和适应窗口，图片读取与解码在后台线程完成。
- 全局快捷键会恢复最小化窗口并调用 Windows 前台激活机制，即使窗口被遮挡也会尽力强制置前并获得焦点。

## 数据和隐私

默认数据目录：

`%LOCALAPPDATA%\ClipboardPlus\`

其中：

- 历史数据库：`clipboard.db`
- 图片缓存：`images\`
- 文件缓存：`files\`

可在“设置 → 数据存放位置”选择新的目录。程序先复制并校验数据库和缓存，再切换到新位置；旧目录会保留为安全备份。设置页同时显示总占用以及文本、图片、文件各自占用。

这是为了兼容 V1 而保留的目录名。所有内容仅保存在本机，不上传网络。数据库迁移前创建的备份也位于同一目录。

最大文本数量默认是 1000；最大普通图片数量是 200；默认文件缓存容量是 512MB。三者独立清理，收藏或固定内容不会被自动删除。

## 开发与测试

运行全部测试：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

代码按职责拆分在 `clipboard_plus` 包中，包括数据库迁移、分类、Windows 热键、来源识别、系统集成、设置界面和主窗口。

平台无关的分类和移动端 SQLite 逻辑位于 `zhumi_core`，避免把 Windows API、托盘和全局快捷键耦合进安卓代码。

## Android 原型

`android_app` 中包含 PySide6 安卓前台原型、部署配置和 APK 构建脚本，支持文本/图片历史、搜索、去重、复制和 SQLite 本地持久化。

Android 10 及以上版本限制普通后台应用读取剪贴板，因此安卓原型只能在应用获得焦点时监听，也提供手动“读取当前剪贴板”按钮。

当前电脑已配置 Android Studio 与 Ubuntu 24.04 WSL 构建环境：Windows 侧用于编辑和连接真机，WSL 侧提供 Qt 所需的 Linux 构建主机、Android SDK/NDK、Python 3.11 虚拟环境和 aarch64 PySide6 wheels。双击 `android_app/open_android_wsl.bat` 打开构建终端，随后可运行下面的无副作用预检：

```bash
bash android_app/verify_wsl_environment.sh
```

此预检不会生成 APK。需要实际生成实体安卓手机（aarch64）安装包时，再在该终端显式运行 `bash android_app/build_apk.sh`。详细环境说明见 `android_app/README.md`。
